# Глоссарий команды

Рабочая версия. Термины нужно проговорить и согласовать всей командой; определения будут уточняться на следующих лабораторных.

| Термин                 | Определение в проекте                                                                                                |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Отзыв                  | Текст и доступные метаданные, опубликованные покупателем о товаре или опыте покупки                                  |
| Источник               | Площадка или файл, откуда получен отзыв, с зафиксированным способом и датой получения                                |
| Набор отзывов          | Ограниченная по товару и времени коллекция отзывов, анализируемая как одна задача                                    |
| Тема                   | Обобщённая категория содержания нескольких похожих отзывов, например доставка или материал                           |
| Проблема               | Тема, подтверждённая отрицательным опытом и потенциально требующая решения бизнеса                                   |
| Кластер                | Группа отзывов, объединённых системой по предполагаемому общему смыслу                                               |
| Семантическая близость | Оценка того, насколько два текста похожи по смыслу, а не только по общим словам                                      |
| Тональность            | Направленность выраженной оценки: положительная, нейтральная, отрицательная или смешанная                            |
| Частота                | Количество отзывов кластера в наборе; всегда указывается вместе с размером набора и периодом                         |
| Тяжесть                | Предварительная оценка последствий проблемы для покупателя или бизнеса; не равна частоте                             |
| Приоритет              | Рекомендация о порядке проверки проблемы человеком с учётом частоты, тяжести и неопределённости                      |
| Неопределённость       | Сигнал, что данных недостаточно для уверенной классификации или рекомендации                                         |
| Дубликат               | Повтор текста или очень похожая запись; сам по себе не доказывает накрутку                                           |
| Подозрительный отзыв   | Отзыв с признаками, требующими ручной проверки; система не утверждает, что отзыв заказной                            |
| Golden dataset         | Версионированный набор примеров с проверенными людьми эталонными метками для оценки качества                         |
| Эталонная метка        | Решение разметчика о теме, тональности, тяжести и допустимых основаниях для вывода                                   |
| Precision              | Доля верных предсказаний среди всех предсказаний выбранного класса                                                   |
| Recall                 | Доля найденных эталонных примеров среди всех эталонных примеров выбранного класса                                    |
| Prompt injection       | Попытка через входной текст заставить модель нарушить заданные правила; отзыв всегда считается недоверенными данными |
| Черновик ответа        | Предлагаемый текст ответа клиенту, который нельзя публиковать без явного подтверждения человека                      |
| North Star             | Главная метрика результата для пользователя, отражающая ценность продукта, а не объём его использования              |
| ADR                    | Запись архитектурного решения: контекст, выбранный вариант, альтернативы и цена компромисса                          |
| Цена решения           | Долг, риск, стоимость или ограничение, которые команда принимает вместе с выбранным подходом                         |
| DoD                    | Проверяемые условия, при выполнении которых артефакт или задача считаются готовыми                                   |
| p95 latency            | Время обработки, быстрее которого завершаются 95% измеренных запросов                                                |
