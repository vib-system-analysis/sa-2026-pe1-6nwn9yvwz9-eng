# Черновик DoD лабораторной 2

Черновик для согласования командой. Критерии написаны так, чтобы проверка могла найти артефакт и подтвердить его содержание.

| Артефакт        | Проверяемое условие                                                                                       | Как проверить                                                         | Статус                                      |
| --------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------- |
| PRD             | Назван один сегмент; есть минимум 3 боли с обстоятельствами; North Star содержит число и способ измерения | Проверить `docs/prd.md` по чек-листу                                  | Черновик есть, значения не согласованы      |
| Гипотезы        | Минимум 3 гипотезы имеют условие опровержения и план проверки                                             | Проверить `docs/hypotheses.md`                                        | Записаны, не проверены                      |
| Глоссарий       | Не менее 15 терминов; определения согласованы вслух и используются одинаково в PRD/брифе                  | Сверить `docs/glossary.md`, отметить дату и участников согласования   | Словарь есть, согласование ожидается        |
| Интервью        | Есть 3–5 обезличенных протоколов по прошлому поведению, согласие и изменение гипотез                      | Проверить `docs/insights.md`; не принимать пустые шаблоны за интервью | Не проведены                                |
| Ресёрч          | Для каждого фактического вывода есть первичная ссылка и дата проверки                                     | Проверить `docs/research.md`; вручную открыть каждую ссылку           | Частично; источники ограничены доступом     |
| Эксперимент     | Зафиксированы версия модели/промпта/данных, повторяемый запуск, ошибки, стоимость и вывод                 | Сверить `docs/experiments/lab1.md` и журнал результатов               | Не запускался                               |
| Метрики         | Каждая метрика имеет порог, формулу/процедуру, выборку и владельца                                        | Проверить `docs/quality/success-criteria.md`                          | Черновые пороги требуют согласования        |
| Golden dataset  | 30–50 разрешённых обезличенных примеров, формат/происхождение/версия зафиксированы; первые 10 из интервью | Проверить манифест и данные; fixture `synthetic` исключить из зачёта  | Не собран                                   |
| Dev environment | `cp .env.example .env && docker compose -f compose.dev.yml up --build` поднимает `/health`                | Запустить на чистой машине с Docker                                   | Конфигурация добавлена, нужен прогон Docker |
| CI              | Workflow проходит lint, format, test, build на PR                                                         | Открыть PR и проверить GitHub Actions                                 | Workflow добавлен, статус ещё не получен    |
| Deploy          | Публичный URL доступен без авторизации и открывает заглушку; процесс описан                               | Открыть URL извне и проверить `/health`                               | Не настроен; URL отсутствует                |
| ADR             | Выбор включает альтернативы и явную цену решения                                                          | Проверить раздел ADR-001 в `docs/research.md`                         | Предварительное решение                     |

DoD финализировать после назначения владельцев и доступа к конкретным требованиям приёмки.
