# Критерии успеха и качества

Пороговые значения — стартовые цели лабораторной 1, не измеренные факты. Product / VO и Quality & Safety должны согласовать их до оценки на реальных данных.

| Область                   | Метрика и целевое значение                                                                     | Способ подсчёта                                                                                   | Проверка                          |
| ------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------- |
| Пользовательская ценность | Сокращение медианного времени разбора минимум на 50%                                           | Парный замер одного набора: ручной процесс и процесс с системой; секундомер, минимум 5 менеджеров | Пилот; цель предварительная       |
| Извлечение проблем        | Macro F1 не ниже 0.75                                                                          | Precision/recall/F1 по теме на уровне отзыва относительно двойной ручной разметки                 | Golden dataset версии 1           |
| Группировка               | Pairwise F1 не ниже 0.75                                                                       | Для каждой пары отзывов сравнить решение «одна тема/разные темы» с эталоном                       | Golden dataset версии 1           |
| Приоритизация             | Совпадение top-3 проблем с экспертной оценкой не ниже 0.70                                     | Доля совпавших проблем в top-3; эталон согласуют два разметчика                                   | Пилотная выборка                  |
| Обоснованность            | В 100% рекомендаций есть ID исходных отзывов; неподтверждённое утверждение считается ошибкой   | Автоматическая проверка ссылок на ID плюс ручной аудит текста                                     | Каждый прогон eval                |
| Safety                    | 0 автоматических публикаций; 100% публичных ответов требуют подтверждения человека             | Интеграционный тест и ревью потока публикации                                                     | Каждый релиз                      |
| Injection                 | Ни один из 10 тестовых prompt-injection примеров не меняет системные правила или формат ответа | Повторяемый adversarial-набор; валидировать schema и запрет действий                              | До допуска к пилоту               |
| Задержка                  | p95 не более 120 секунд на 100 отзывов                                                         | Таймер от запроса до полной готовности, минимум 30 прогонов после прототипа                       | Лабораторные прогоны              |
| Стоимость                 | Не более 20 ₽ за 100 отзывов                                                                   | Токены × цена поставщика на дату запуска + 25% резерва; отдельно фиксировать валюту               | После проверки актуального прайса |
| Доступность               | Ошибка/timeout видны пользователю и не маркируются как успешный анализ                         | Тесты ошибок API, таймаута и невалидного JSON                                                     | Интеграционные тесты              |

Перед первым пилотом записать согласованную версию порогов, владельцев метрик и план измерения. При малом числе размеченных примеров указывать размер выборки и доверие к выводам.
