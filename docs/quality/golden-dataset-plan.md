# План golden dataset

## Цель и объём

К лабораторной 2 собрать 30–50 обезличенных пар «отзыв → эталон». Первые 10 должны происходить из проблемных интервью и содержать живые формулировки только с разрешения респондента. Сейчас интервью и реальные записи отсутствуют.

`data/synthetic-reviews.jsonl` содержит 10 явно синтетических строк только для проверки формата; они не являются golden dataset и не засчитываются в объём.

## Источники и ограничения

Приоритет: примеры из интервью с документированным согласием, затем разрешённые публичные данные с зафиксированным URL/датой/условиями получения. Не обходить авторизацию, rate limit или условия площадки. Удалять имя, контакты, номера заказов и иные лишние идентификаторы; не сохранять закрытые кабинеты. Для каждого источника записывать основание использования и ограничения хранения.

## Формат

JSONL, одна запись на строку:

```json
{
  "id": "ex-001",
  "text": "Обезличенный текст отзыва",
  "source": {
    "kind": "interview|public|synthetic",
    "reference": "opaque-reference",
    "collected_at": "YYYY-MM-DD",
    "consent_or_basis": "documented"
  },
  "labels": {
    "theme": "delivery",
    "sentiment": "negative",
    "severity": "medium",
    "suspicious": false
  },
  "rationale": "Короткое объяснение метки",
  "annotators": ["reviewer-1", "reviewer-2"],
  "status": "adjudicated"
}
```

Темы и шкалы согласовать до разметки. Два человека размечают независимо; разногласия обсуждаются и записываются. Набор версионируется, изменения не перезаписывают предыдущую оценку.

## Баланс и split

Планировать разные категории, тональности, длины и тяжесть; не допускать, чтобы дубликаты попали в разные split. Разделять train/dev/test по товару или временному периоду, если объём позволит. На 30–50 примерах метрики считать ориентировочными и показывать размер выборки.

## Владелец и состояние

Владелец: Quality & Safety (участник пока не назначен). Доступ ограничить команде. Версия 0.1: только синтетический fixture; эталонные метки интервью не собраны. До пилота подтвердить права, обезличивание, сроки хранения и процедуру удаления.
