# Запуск и деплой

## Локально

Требуется Node.js 22+.

```sh
npm ci
npm start
```

Приложение слушает `0.0.0.0:$PORT` (по умолчанию порт 3000). `GET /` возвращает `Hello, world!`, `GET /health` — JSON `{"status":"ok"}`.

## Dev через Docker Compose

```sh
cp .env.example .env
docker compose -f compose.dev.yml up --build
```

Проверить `http://localhost:3000/health`. Остановить окружение: `docker compose -f compose.dev.yml down`.

## Публичный деплой

Публичного URL пока нет. Для публикации нужен выбранный командой хостинг, доступ к проекту и проверка разрешённого региона/обработки данных. Образ строится из `Dockerfile`; приложение использует переменную `PORT` и health endpoint `/health`. Перед публикацией не передавать ключи в образ или репозиторий; secrets хранить в настройках хостинга.
